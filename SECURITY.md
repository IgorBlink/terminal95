# Security

For a security issue, use [GitHub private vulnerability reporting](https://github.com/IgorBlink/terminal95/security/advisories/new) if it is available. If private reporting is unavailable, open an issue asking for a private contact channel without including exploit details or credentials.

Please include the affected version, operating system, terminal, and reproduction steps. Do not include access tokens, authentication files, or private conversation transcripts in a public issue.

The optional chat launches the installed Codex CLI and uses its existing authentication. It does not need a separate API key when the CLI is already authenticated through ChatGPT. Its default Codex sandbox is read-only. Terminal95 theme profiles only change appearance.

Security fixes are made on the current main branch. Affected older versions may require an update.
