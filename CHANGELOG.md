# Changelog

## 0.1.0 (2026-11-09)

- Apply a gray Windows 95-inspired style with the bundled pixel font and classic PC colors.
- Import profiles for Ghostty, Kitty, Alacritty, WezTerm, Windows Terminal, and iTerm2, or try the colors in a compatible terminal with `scripts/theme.sh`.
- Optionally chat with Codex in the current terminal using `codex95`, with streamed replies and a small waiting indicator.
- Resume a conversation after restarting without reprinting its previous messages.
