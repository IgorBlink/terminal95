This font uses square pixel outlines based on an 8-by-16 grid. The Plus
character set includes Latin, Cyrillic, Greek and Hebrew. The family name
to select in a terminal is exactly: PxPlus IBM VGA 8x16

For a crisp bitmap appearance, render at integer multiples of 16 physical
pixels tall. On a typical 2x macOS display, a 16-point em corresponds to
32 physical pixels. Display scaling and terminal metrics can affect this.
